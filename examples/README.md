# Examples

**All data in this folder is fictional.** Kestrel Home Insights, its reports, figures, companies and people are invented for demonstration. Email addresses use the reserved `example.com`, `example.org` and `example.net` domains.

| File | Used by | Shows |
|---|---|---|
| [`sample-report-excerpt.md`](sample-report-excerpt.md) | report-to-article | The source material |
| [`sample-article.md`](sample-article.md) | report-to-article | A public article built from it |
| [`sample-verification-table.md`](sample-verification-table.md) | report-to-article | How each claim is traced |
| [`contacts.csv`](contacts.csv), [`blocklist.csv`](blocklist.csv), [`already_received.csv`](already_received.csv) | email-list-builder | A messy contact export with duplicates, customers, unsubscribes and invalid addresses |
