# Site checklist for AI and search crawlers

- [ ] Core facts (who you are, what you offer, where you operate) are on crawlable HTML pages, not only in images or PDFs.
- [ ] Each core page has a clear title and a one-paragraph summary at the top.
- [ ] `robots.txt` allows the crawlers you want.
- [ ] `sitemap.xml` lists the core pages with last-modified dates; update it when pages change.
- [ ] `llms.txt` at the site root gives a short, plain description of the company, its core definitions and links to stable pages.
- [ ] FAQ pages use structured data (FAQPage) where appropriate.
- [ ] Company name, description and key numbers are identical across the site, profiles and directories.
- [ ] The site is reachable from the markets you care about.
