# Verification table

One row per factual statement in the article.

| # | Statement as used in the article | Source | Location | Original scope (time, market, sample, unit) | Support | Disclosure tier |
|---|---|---|---|---|---|---|
| 1 | | | p. / slide | | direct / calculated / inference / to confirm | public / gated / private |

## Support levels

- **Direct:** the source states it.
- **Calculated:** derived from source figures. Keep the formula and inputs, and say "calculated from" in the article.
- **Inference:** a reasonable reading of the source. Do not present it as the source's conclusion. Prefer to remove it.
- **To confirm:** cannot be traced yet. It does not go into a published article.
