# Layout and accuracy checks

## Accuracy

- [ ] No missing pages, slides, paragraphs, table cells or chart labels.
- [ ] Every number, unit, percentage and range matches the source.
- [ ] Glossary terms used consistently; departures listed.
- [ ] Punctuation, full-width and half-width characters follow the target language's conventions.
- [ ] Image captions still match their images.

## Layout (inspect the rendered file)

- [ ] No text cut off or overflowing its box.
- [ ] No unexpected line breaks, widows or page breaks.
- [ ] Fonts available and not substituted; no garbled characters.
- [ ] Tables fit the page; charts and images are sharp.
- [ ] Headers, footers and page numbers correct.
- [ ] The file opens without a repair prompt.
