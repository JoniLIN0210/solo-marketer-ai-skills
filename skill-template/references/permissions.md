# Permission levels

These five levels are independent. Permission for one does not imply permission for the next.

| Level | Example | Needs explicit approval in the current task? |
|---|---|---|
| 1. Prepare | Write a draft file on your computer | No, if the user asked for it |
| 2. Save a draft on a platform | Log in and save an unpublished post | Yes |
| 3. Submit for review | Submit a post or form to a platform's review queue | Yes |
| 4. Publish or send | Make a post public; send an email or message | Yes |
| 5. Change live data or settings | Edit a live web page, account setting or database | Yes |

## Wording guide

- "Help me prepare..." authorises level 1 only.
- "Save it as a draft" authorises level 2 only.
- "Publish it" authorises level 4 for that item only. It does not carry over to the next item.

## After any external action

Record the platform, item, time, status and public link. Read the status back from the platform's management page; a confirmation message is not proof.
