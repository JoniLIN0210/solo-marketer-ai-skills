# Definition of done

A task is finished only when all of the following are true.

## Scope

- [ ] The deliverable covers exactly what was asked, with nothing missing and nothing unrequested added.
- [ ] File names and versions are clear. Temporary files are not delivered.

## Facts and sources

- [ ] Every number, ranking, growth rate, quote and example has a source location.
- [ ] Time period, market, sample, category and unit are preserved.
- [ ] Calculated figures are labelled as calculated, with inputs kept.
- [ ] Inferences are not presented as source statements.
- [ ] No block-listed source is cited.
- [ ] No unsupported superlatives ("first", "fastest", "leading").

## Confidentiality and privacy

- [ ] Public content stays within the agreed disclosure tier.
- [ ] Personal data, customer names and internal notes are removed or masked for the intended audience.
- [ ] No secrets (passwords, keys, tokens) appear anywhere.

## Files

- [ ] The file opens without repair prompts.
- [ ] Every page or slide has been rendered and inspected for cut-off text, overflow, missing fonts, broken images and wrong page numbers.
- [ ] Spreadsheets have been checked for row counts, duplicates, empty values, formulas and readable formatting.

## External actions

- [ ] The permission level for this task was confirmed (prepare / draft / submit / publish or send / change live settings).
- [ ] The real status was read back from the platform after any action.
