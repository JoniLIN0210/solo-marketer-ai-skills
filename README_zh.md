# 一人市场团队的 AI Skills（中文说明）

英文原版见 [README.md](README.md)。

这个仓库收录了一套给「一个人做 B2B 市场」用的 AI Skills，以及背后的方法。

大多数「AI 做营销」的资料是一堆提示词。提示词写起来容易，但不可靠：AI 会忘掉你的规则、编造数字，还会悄悄做你没批准的事。这里换了一种做法：每个 Skill 写清楚**这件事应该怎么做**——哪些来源算数、什么绝不能公开、怎样才算「做完」、哪些动作必须由人来点确认。这样 AI 每次都按同样的标准做，你也能检查它有没有做到。

这些内容来自我在一家 B2B 数据公司独自负责市场工作的经验，内容、线索、邮件、展会和销售支持都由一个人承担。所有公司信息都已去除，示例全部使用虚构公司。

## 里面有什么

| 目录 | 内容 |

| [`docs/`](docs/) | 方法：怎么选任务、写规则、设护栏、做核验、维护和迁移 |

## 怎么用

1. 挑一个和你每周工作最接近的 Skill。
2. 安装：Claude Code 放到项目的 `.claude/skills/` 或 `~/.claude/skills/`；Claude 网页和桌面端打包上传为自定义 Skill；其他 AI 工具在 `AGENTS.md` 等说明文件里写一句「做邮件名单时按 skills/email-list-builder/SKILL.md 执行」。
3. 修改文件里标着 `CONFIGURE` 的部分：禁用来源、受众分层、发送限制等。
4. 正式使用前先跑一遍 [`evals/`](evals/) 里的用例。

## 五条原则

1. **规则写一次。** 同一件事给 AI 解释过两次，就该写进 Skill。
2. **事实要有出处。** 找不到出处的数字标为缺失，不填补。
3. **准备不等于发布。** 起草、存草稿、提交、发布、改线上配置是五种不同的授权。
4. **「生成了」不等于「做完了」。** 文件要打开检查，名单要查泄漏，平台状态要回读。
5. **改一类，不改一个。** 发现一个错误，就查同类的所有错误。
