# Task selection worksheet

Copy this table, list the tasks you repeated in the last two months, and score each one.

Scoring: 2 = clearly yes, 1 = partly, 0 = no. For "cost of error", score 2 when mistakes are caught before anyone outside sees them.

| Task | Frequency | Rules can be written | Result can be checked | Cost of error is contained | Total | Decision |
|---|---|---|---|---|---|---|
| Example: turn a monthly report into a newsletter article | 2 | 2 | 2 | 2 | 8 | Build a skill now |
| Example: build an email list for a topic campaign | 2 | 2 | 2 | 1 | 7 | Build a skill; a person sends the email |
| Example: reply to a key customer's complaint | 1 | 1 | 0 | 0 | 2 | Keep it human; AI may draft notes only |
| | | | | | | |
| | | | | | | |

## How to decide

- **7–8:** build a skill now.
- **5–6:** build a skill, but keep a person on every external action.
- **4 or lower:** do not automate. Use AI for drafts or research at most.
